> ملاحظة: أي رقم عراقي آخر (يبدأ بـ 9647...) سيُرسل رمزاً حقيقياً عبر OTPIQ (WhatsApp/SMS مع fallback تلقائي).

## تدفق الاختبار

1. افتح التطبيق واختر "تسجيل الدخول" أو "إنشاء حساب".
2. أدخل الرقم بصيغة `7723370753` أو `9647723370753` أو `+9647723370753` (سيُوحّد تلقائياً لـ +964).
3. اضغط إرسال الرمز، ثم أدخل `123456`.
4. سيتم تأكيد الرقم والدخول للتطبيق.
